# 计算所实习：传统全栈复盘任务清单

> 只把需要学习、输出或演练的事项计入进度。原则、事实边界和禁止表述保留为公告，不计入任务总数。

## 公告

### 使用原则

- 每项任务必须产出笔记、代码、图或口头回答之一，单纯“看过”不算完成。
- 项目回答统一采用：背景与约束 -> 我的职责 -> 方案 -> 结果 -> 局限与改进。
- 复盘范围只覆盖传统全栈与模型服务化；Agent、RAG、Prompt 和状态机放到课程设计专项。

### 医疗智能诊断平台：事实边界

- 既有 SSM / Spring Boot 平台和五个深度学习模型不是从零开发或训练的。
- 个人核心贡献是 Flask 服务化、Nacos / OpenFeign 接入、前端复核流程和持久化衔接。
- `langchain4j-llm-rag` 属于学长工作；项目没有真实完成 Redis、Kafka、Sentinel 和性能压测。
- 五模型没有显式实现轮询负载均衡；放射科批准 / 驳回也没有形成完整持久化状态机。

### 考古玉器数字化平台：事实边界

- Python 版是早期探索，Java 版是导师要求下的主系统方案。
- 金字塔瓦片方案来自调研；Nexus 是外部 C++ 库，个人贡献是选型、接入和效果验证。
- 八叉树与 Cesium 跑过对照实验，但没有开发底层渲染引擎或 Nexus 算法。
- 1% 是实际测量误差结果；没有正式记录的数据不写成首屏耗时或吞吐指标。

### 北中医临床数据平台：事实边界

- 个人贡献集中在需求沟通、患者与检查数据建模、字段口径和 Excel 映射方案。
- 整个 Spring Boot + Vue 平台、权限体系和部署体系不是个人独立完成。
- 只有能够完整解释校验、事务与回滚流程时，才在面试中展开批量导入方案。

### 面试红线

- 不声称从零开发完整医疗平台、训练五个模型或独立完成北中医整个平台。
- 不声称通过 Redis、Kafka、Sentinel 实现高并发治理，也不使用虚构的 QPS、TPS 和响应时间。
- 不声称五模型采用轮询负载均衡或完整实现放射科审批状态持久化。
- 不声称开发 Nexus、八叉树或底层图形引擎。
- 被追问他人模块时，先明确协作边界，再回答自己理解的接口与原理。

## 1. 项目答辩交付

### 核心材料（P0）

- [ ] 写出三个项目各自的 1 分钟和 3 分钟介绍，3 分钟版本必须包含一条完整数据链路。
- [ ] 为三个项目各画一张可在白板复现的架构图，并标出个人负责范围。
- [ ] 每个项目整理 2 个真实问题、解决过程、方案取舍和当前缺陷。
- [ ] 建立代码证据索引：简历中的每个核心动词都能定位到接口、类、表或页面。
- [ ] 完成一次 30 分钟项目压力面试并记录未答稳的问题。

## 2. 医疗智能诊断平台

### 服务接入与数据链路（P0）

- [ ] 画出五类模型的输入、输出、HTTP 方法、端口、临时文件与 GPU 使用对照表。
- [ ] 手写一个最小 Flask 推理服务，完成模型单次加载、参数校验、异常处理和结构化响应。
- [ ] 画出 Spring Boot 经 Nacos 发现 Flask 服务并由 OpenFeign 发起调用的完整链路。
- [ ] 解释注册、发现、心跳、实例摘除、注销和多实例负载均衡之间的关系。
- [ ] 为五类模型设计统一 API 契约、错误码、请求 ID、超时和日志字段。

### 人工复核与可靠性（P0）

- [ ] 画出推理、医生修改确认、consultation 主表与专科表事务入库流程。
- [ ] 解释远程模型调用为什么不应置于长事务，以及本地多表写入为什么需要事务。
- [ ] 复现实验 `@Transactional` 的正常回滚、异常被吞和同类内部调用失效场景。
- [ ] 为重复确认设计幂等键、唯一约束和结果复用方案。
- [ ] 为放射科补画待推理、待复核、已确认、已拒绝、保存失败状态机。

## 3. 考古玉器数字化平台

### 二维瓦片与三维 LOD（P0）

- [ ] 画出视口变化、计算 `{z}/{x}/{y}`、拼接路径、请求瓦片和浏览器缓存的链路。
- [ ] 解释只保存路径模板与元数据的收益，以及文件迁移、瓦片缺失和版本一致性问题。
- [ ] 说明瓦片大小、层级数量、预加载、并发请求、首屏速度与清晰度的取舍。
- [ ] 对比八叉树、Cesium 与 Nexus 的首次加载、近景精度、视觉缺陷和接入成本。
- [ ] 解释 LOD、屏幕误差、摄像机距离与视锥剔除各自解决的问题。

### 测量、坐标与标注（P0）

- [ ] 推导像素距离到现实距离的换算公式，并明确 1% 误差的真值与测试口径。
- [ ] 画出屏幕坐标、图像坐标和原图像素坐标在缩放平移后的转换过程。
- [ ] 复现标注与视角拖动的事件冲突，并用编辑模式或 Pointer Events 分离交互。

## 4. 北中医临床数据平台

### 数据建模（P0）

- [ ] 画出患者、检查记录、科室来源与具体诊疗数据的简化 ER 图。
- [ ] 解释 `patient_id`、`record_id`、`source`、`exam_no` 的业务含义与约束。
- [ ] 设计同名患者、多次检查、信息纠错和重复数据的识别策略。
- [ ] 用真实字段说明一对一、一对多、唯一约束、三范式和适度反范式。

### Excel 导入（P0）

- [ ] 画出三级表头到关系表字段的映射、类型校验、冲突检测和错误报告流程。
- [ ] 对比整表事务与分批事务，并设计导入幂等键和失败重试方案。
- [ ] 手写一个最小 Excel 批量导入程序，覆盖合并单元格、空值、日期和重复上传测试。

## 5. Java 与 JVM

### Java 核心（P0）

- [ ] 手写一个 Java 小程序，覆盖集合、泛型、参数校验、异常处理、equals 与 hashCode。
- [ ] 解释并实测 HashMap 的结构、扩容、冲突处理及与 ConcurrentHashMap 的区别。
- [ ] 完成 synchronized、volatile、Lock、原子类和线程池的最小并发实验。
- [ ] 分析模型推理任务的线程池参数、排队、拒绝策略和无限建线程风险。

### JVM 核心（P1）

- [ ] 画出运行时内存区域，并区分栈溢出、堆 OOM、元空间 OOM 和内存泄漏。
- [ ] 解释类加载、双亲委派、对象创建到回收的过程。
- [ ] 对比复制、标记清除、标记整理以及 Serial、Parallel、CMS、G1 的适用差异。
- [ ] 用 happens-before 解释可见性、有序性和 `volatile` 不能保证 `count++` 原子性的原因。

## 6. Spring 与 MyBatis

### 框架链路（P0）

- [ ] 手写最小 Spring Boot + MyBatis CRUD，包含 Controller、Service、Mapper、校验和全局异常处理。
- [ ] 解释 IoC、DI、AOP、Bean 生命周期、默认作用域和线程安全问题。
- [ ] 画出一次 Spring MVC 请求从过滤器到 Controller、Service、Mapper 和数据库的链路。
- [ ] 解释 JDK / CGLIB 动态代理以及 Feign、MyBatis 接口无实现类仍能工作的原因。
- [ ] 用实际 SQL 说明 `#{}`、`${}`、resultMap、动态 SQL、分页和 N+1 查询问题。

## 7. MySQL

### 索引与 SQL（P0）

- [ ] 解释 B+ 树、聚簇索引、二级索引、回表、覆盖索引和联合索引最左匹配。
- [ ] 为患者查询和检查记录查询设计索引，并使用 `EXPLAIN` 验证。
- [ ] 手写 JOIN、聚合、查重、Top N、保留最新记录和深分页优化 SQL。

### 事务、MVCC 与锁（P0）

- [ ] 解释 ACID、四种隔离级别以及脏读、不可重复读和幻读。
- [ ] 画出 InnoDB 版本链、undo log、Read View 与 MVCC 可见性判断。
- [ ] 区分 redo log、undo log、binlog、行锁、间隙锁、临键锁、乐观锁与悲观锁。
- [ ] 复现一次主子表回滚和一次并发死锁，并说明检测与规避方法。

## 8. HTTP、接口与模型服务

### 网络与 API（P0）

- [ ] 解释从输入 URL 到 HTTP 响应的 DNS、TCP、TLS、代理与应用处理链路。
- [ ] 设计图片、视频和 Excel 上传接口，说明 JSON、查询参数和 multipart 的边界。
- [ ] 为同步推理与异步任务分别设计 API，并处理超时、重试、重复提交和任务查询。
- [ ] 解释 Cookie、Session、JWT、CORS、401、403、409、429、502、503、504。

### Flask 服务工程化（P1）

- [ ] 用 Gunicorn 部署 Flask 服务，并解释 worker 数、模型内存、GPU 显存和请求排队。
- [ ] 为 URL 下载输入补齐 SSRF 防护、白名单、超时、大小限制、MIME 校验和临时文件清理。

## 9. 工程化与排障

### 部署与诊断（P1）

- [ ] 为 Spring Boot 与 Flask 服务分别编写最小 Dockerfile，并完成本地构建运行。
- [ ] 配置一次 Nginx 反向代理，验证 HTTPS、上传大小、超时和静态资源缓存。
- [ ] 按“浏览器 -> Java -> Flask -> OSS / DB”完成一次分段故障定位并整理日志证据。
- [ ] 掌握 Git 分支、merge、rebase，以及 Linux 进程、端口、磁盘、日志和权限排查命令。

## 10. 算法与手写

### 必做能力（P0）

- [ ] 用 Java 完成数组 / 哈希、双指针、滑动窗口各 3 道典型题。
- [ ] 完成链表、二叉树、堆、二分、栈 / 队列各 2 道典型题。
- [ ] 完成动态规划 3 题与 SQL 5 题，主动说明复杂度和边界条件。
- [ ] 手写线程安全单例、生产者消费者和带事务的主子表保存伪代码。
- [ ] 完成两次 45 分钟限时中等题，禁止 AI 补全并复盘错误。

## 11. 投递验收

### 验收门槛（P0）

- [ ] 三个项目都能脱稿讲满 3 分钟，并能稳定划分个人与团队贡献。
- [ ] 每个项目的两条核心链路都能连续承受三层追问。
- [ ] Java、Spring、MySQL、HTTP 的 P0 项完成率达到 90%。
- [ ] 完成一次完整模拟面试：30 分钟项目、20 分钟八股、45 分钟手写。

## 建议学习顺序

1. 三个项目的数据链路、架构图与代码证据。
2. MySQL 事务、索引、MVCC 与锁。
3. Spring MVC、AOP 事务与 MyBatis。
4. Java 集合、异常、并发与 JVM。
5. HTTP、Nacos、Feign 与 Flask 工程化。
6. 北中医数据建模与 Excel 导入。
7. 考古瓦片、LOD、坐标与事件系统。
8. Git、Linux、Docker、日志与基础算法。
