# 计算所实习：传统全栈复盘任务清单

> 适用范围：中国科学院计算技术研究所实习经历，以及由这段经历引出的 Java、Spring、MySQL、网络、Flask、前端与工程化问题。
>
> 明确排除：LLM、Prompt、Function Calling、RAG、Agent 状态机、Agent 记忆与评测。这些内容放到两个课程设计项目的独立复盘中。

## 0. 使用规则

- [ ] 每个知识点至少达到“能用自己的话解释”，不能只背一句定义。
- [ ] 标记为 **P0** 的任务，投递前必须完成；**P1** 在首轮面试前完成；**P2** 在秋招过程中补齐。
- [ ] 每个项目准备 1 分钟、3 分钟、10 分钟三种讲法。
- [ ] 回答项目问题统一采用：背景与约束 -> 我的职责 -> 方案 -> 结果 -> 局限与改进。
- [ ] 面试中分清“我实现的”“团队已有的”“使用的开源组件”，不把参与写成从零主导。
- [ ] 不在这段实习中主动引出 Agent；如果面试官询问 AI，只讨论模型服务化和 AI 应用接入。
